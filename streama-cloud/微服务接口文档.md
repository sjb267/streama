# 微服务接口文档

## 1. 文档说明
- 更新时间：2026-04-17。
- 文档基于当前 streama-cloud 代码仓整理，采用“代码优先”口径。
- 本文档仅描述网关对外路径，不包含内部调用接口（如 /innerApi/**）。
- 本次为文档重构，不新增/删除运行时 API，仅校准文档契约。
- 当前对外接口总数：62（/web 29、/interact 13、/admin 13、/file 7）。

## 2. 网关与服务路由
- 网关统一入口：http://{host}:7071
- 路由规则（StripPrefix=1）：

| 网关前缀 | 目标服务 | 默认端口 | 备注 |
| --- | --- | --- | --- |
| /web/** | streama-cloud-web | 7072 | Web 业务接口 |
| /interact/** | streama-cloud-interact | 7073 | 互动业务接口 |
| /admin/** | streama-cloud-admin | 7070 | 管理端业务接口 |
| /file/** | streama-cloud-resource | 7074 | 资源与文件接口 |

> 说明：AdminFilter 在网关侧仍为未闭环实现，文档中的“登录要求”以 Controller 上 @GlobalInterceptor(checkLogin=true) 为准。

## 3. 公共约定
### 3.1 响应结构（ResponseVO）
```json
{
  "status": "success",
  "code": 200,
  "info": "请求成功",
  "data": {}
}
```

### 3.2 常见业务码
| code | 含义 |
| --- | --- |
| 200 | 请求成功 |
| 404 | 路径不存在/资源不存在 |
| 500 | 服务内部异常 |
| 600 | 参数错误/业务校验失败 |
| 601 | 数据已存在 |
| 901 | 未登录或登录过期 |

### 3.3 登录态与 Token
- Web/Interact/Resource 侧登录态：token。
- Admin 侧登录态：adminToken。
- 登录接口会写入 Cookie；业务请求通常通过 Header 读取 token。
- “登录要求（代码声明）”字段仅反映注解声明，不等价于网关层已经统一强校验。

### 3.4 参数来源规则
- 普通参数来源：Controller 方法签名与校验注解（@NotNull、@NotEmpty、@Size、@PathVariable）。
- Query 对象展开：CategoryInfoQuery、VideoInfoPostQuery、BaseQuery。
- 文件上传接口统一使用 multipart/form-data。

### 4.4 搜索排序 orderType（/web/video/search）
| 值 | 含义 |
| --- | --- |

| 值 | 含义 |
| --- | --- |
| 0 | 自制 |

### 4.6 互动位 interaction
- 字符串包含 0：关闭评论区。
- 字符串包含 1：关闭弹幕。

### 4.7 注册密码规则
- 参数：registerPassword
- 正则：^(?=.*\d)(?=.*[a-zA-Z])[\da-zA-Z~!@#$%^&*_]{8,18}$
- 含义：8-18 位，必须包含数字与字母，可含 ~!@#$%^&*_。
